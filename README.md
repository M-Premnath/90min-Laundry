# 🧺 Laundry Management System

A **complete laundry management web application** designed to simplify and automate laundry operations — from order booking to delivery tracking — with separate dashboards for **Admin**, **Branch Managers** and **Staff**. Reports for **Inventory**, **Staffs**, **Order Status Report** and **Weekly Order**

This project helps streamline laundry business operations with an intuitive interface, real-time updates, and easy accessibility.

---

## 🚀 Features

### 🌐 Website (Customer Side)
- Customers can place laundry orders online.  
- View available services (Wash & Fold, Wash & Iron, Dry Cleaning, Steam Iron).  
- Track order status in real-time.  
- Receive notifications on order progress and delivery.  

### 🧑‍💼 Admin Dashboard
- Manage all branches, staff, and customers in one place.  
- View and manage all orders and transactions.  
- Generate reports and monitor business analytics.  
- Update pricing, offers, and service categories.  

### 🏢 Branch Dashboard
- Manage branch-specific orders.  
- Assign tasks to staff members.  
- Track order completion and delivery status.  

### 👕 Staff Dashboard
- View assigned orders with customer details.  
- Update order progress (Picked, Washing, Ready, Delivered).  
- Manage daily work reports.
